<Step>

### Get an API key

Keys are issued by the OpenGrid team. Email <Contact /> with your company and what you want to build, and you will
get a key that starts with `opg_live_`.

Keep it out of source code. Store it in an environment variable:

```bash
export OPENGRID_API_KEY="opg_live_..."
```

</Step>
<Step>

### Make your first request

Ask for the current market of three GPUs:

<Tabs items={['curl', 'Python', 'JavaScript']}>
<Tab value="curl">

```bash
curl "https://data.tryopengrid.com/v1/markets?limit=3" \
  -H "Authorization: Bearer $OPENGRID_API_KEY" \
  -H "OpenGrid-Version: 2026-11-03"
```

</Tab>
<Tab value="Python">

```python
import os
import requests

r = requests.get(
    "https://data.tryopengrid.com/v1/markets",
    params={"limit": 3},
    headers={
        "Authorization": f"Bearer {os.environ['OPENGRID_API_KEY']}",
        "OpenGrid-Version": "2026-11-03",
    },
    timeout=30,
)
r.raise_for_status()
for row in r.json()["data"]:
    print(row["gpu"], row["price"]["low"], row["price"]["median"])
```

</Tab>
<Tab value="JavaScript">

```js
const r = await fetch('https://data.tryopengrid.com/v1/markets?limit=3', {
  headers: {
    Authorization: `Bearer ${process.env.OPENGRID_API_KEY}`,
    'OpenGrid-Version': '2026-11-03',
  },
});
if (!r.ok) throw new Error((await r.json()).error.message);
const { data } = await r.json();
for (const row of data) console.log(row.gpu, row.price.low, row.price.median);
```

</Tab>

### Read the response

Every success has the same envelope: your data in `data`, and request facts in `meta`.

```json

      "gpu_name": "NVIDIA H100 80GB SXM5",
```

<Step>

### Go further

- Get one GPU's price over time: `GET /v1/markets/nvidia-h100-80gb-sxm5/history?window=7d`.
- See every individual offer: `GET /v1/listings?gpu=nvidia-h100-80gb-sxm5`.
- Page through long lists with `cursor`. See [Pagination](/pagination).

</Step>

## Try it in the browser

Every page in the [API reference](/api-reference) has a playground. Paste your key into it, and requests go straight
from your browser to `data.tryopengrid.com`. Your key is stored only in your browser.
