## The playground

<Callout title="Bring your own key">
  The playground calls the real API with **your** key. Paste it into the authorization field of any endpoint and
  press **Send**. Requests go straight from your browser to `data.tryopengrid.com`, never through this site. Without
  a key, every request returns `401`. Don't have a key? Email <Contact />.
</Callout>

- Your key is stored only in this browser's local storage, so you don't need to paste it again on the next page.
  Clear it from the authorization field when you're done on a shared machine.
- Requests count against your key's [rate limit](/rate-limits) like any other.
- This site may only send requests to `data.tryopengrid.com`. Its content security policy blocks every other
  destination.

## Conventions

- Send `Authorization: Bearer opg_live_...` and, ideally, `OpenGrid-Version: 2026-11-03`. See
  [Authentication](/authentication) and [Versioning](/versioning).
- Successes are `{"data": ..., "meta": ...}`, and errors are `{"error": {...}}`. See [Responses](/responses).
- Lists page by `cursor`. See [Pagination](/pagination).

## Machine-readable
